# QSO Practice Project

A small practice website made to learn project structure and the Git workflow (clone, commit, push).

## Files

- `index.html`: the home page, with links to the other pages
- `about.html`: a short page about me
- `projects.html`: a page for projects I am working on
- `contact.html`: a page with my contact details
- `images/`: folder for images (empty for now)
- `css/`: folder for stylesheets (empty for now)
- `js/`: folder for JavaScript files (empty for now)
